# UI Checklist: Компонентная структура UI

- [x] CHK001 Страница содержит только композицию, клиентское состояние вынесено.
- [x] CHK002 Ввод ниши, переключатели, лимит и кнопка отдельные компоненты.
- [x] CHK003 Кнопка поддерживает `type="submit"`.
- [x] CHK004 Разбор состоит из панели и переиспользуемых элементов.
- [x] CHK005 Фильтр слов и таблица вынесены отдельно.
- [x] CHK006 Строки и метаданные снимка не захардкожены в JSX.
- [x] CHK007 Плашки «Локальный прототип» и «Свободная формулировка» отсутствуют.
- [x] CHK008 Стили лежат в `.module.scss` рядом с компонентами, используют БЭМ и вложенность; адаптивные правила сохранены.
- [x] CHK009 Тесты и сборка проходят; визуальная проверка отражена честно.
- [x] CHK010 Каждый компонент находится в своей папке; импорты идут через `index.ts`.
- [x] CHK011 Типы props описаны непосредственно в компонентах; локальные константы лежат рядом, общие константы вынесены отдельно.
- [x] CHK012 Все цвета и шрифты заданы в общих SCSS-токенах; повторяющиеся блоки вынесены в миксины.
- [x] CHK013 Повторяющиеся элементы таблицы, сводки, фильтра и переключателей создаются из массивов через отдельные функции рендера.

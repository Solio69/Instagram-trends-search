# Проверка SCSS для текущего Next.js

Локальная документация `node_modules/next/dist/docs/01-app/02-guides/sass.md` подтверждает: Next.js поддерживает Sass после установки пакета `sass`, компонентные стили используют файлы `.module.scss`. Дополнительная настройка `next.config` для этого не требуется. Для текущего проекта достаточно `npm install --save-dev sass`.

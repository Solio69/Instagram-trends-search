# Implementation Plan: Экран анализа ниши

**Branch**: `001-niche-results-ui` | **Date**: 2026-10-29 | **Spec**: [spec.md](./spec.md)

## Summary

Заменить демонстрационные карточки экраном ввода с поэтапным показом примера формализации и таблицы снимка Apify после нажатия кнопки. Два таймера примерно по секунде имитируют работу модели и поиск. Локальные функции применяют период, формат, выбранные слова, ограничение и сортировку; браузер скачивает текущую выдачу в JSON. После загрузки страница прокручивается к таблице. Новые пакеты и API не нужны.

## Design

- `Mox/apify-fitness-posts.json`: компактный снимок 50 реальных публикаций без временных ссылок на медиа.
- `Mox/formalization.json`: явно помеченный пример результата первой модели для фразы про healthy нишу. Это статические данные.
- `app/lib/results.ts`: чистая функция фильтра по периоду, формату и любому из выбранных фактически совпавших терминов, сортировки по метрике или дате, обрезки списка и ограничения текста; тесты с краевыми случаями.
- `app/page.tsx`: клиентский экран со стадиями `idle → loading-breakdown → loading-posts → complete`, очисткой таймеров при изменении запроса и скачиванием JSON через `Blob`.
- `app/globals.css`: адаптивная верстка таблицы и панели.

Период считается относительно фиксированного времени завершённого запуска, заданного в `app/page.tsx`. Это сохраняет детерминированность демонстрационной выдачи. Экспорт использует уже рассчитанный список строк, поэтому порядок и длина совпадают с таблицей.

## Verification

1. Red/Green: тест сортировки, фильтров периода, формата, ключевого слова и лимита.
2. Сборка `npm run build`.
3. Браузер: до нажатия нет разбора и таблицы; после нажатия индикатор проходит два положения, затем доступны сортировка, галочки для нескольких слов и JSON. Проверить формат рядом с периодом, фокус по клику в любой точке рамки лимита и замену числа набором с клавиатуры, пустое состояние при словах без совпадений, порядок «поле → настройки → кнопка → разбор → таблица», предел 150 символов и лимит строк. Если браузерный доступ ограничен, проверить структуру связанного `<label>` и сборку, не выдавая это за проверку клика.

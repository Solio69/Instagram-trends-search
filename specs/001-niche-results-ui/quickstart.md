# Проверка экрана

1. `npm run dev`
2. Открыть `http://localhost:3000`.
3. При первом открытии убедиться, что разбора и таблицы нет. Ввести нишу, выбрать период, формат и вручную набрать лимит, затем нажать «Показать тренды». После двух этапов загрузки проверить переход к таблице, сортировку и галочки по нескольким словам, скачать JSON и сравнить строки и настройки с таблицей.
4. `npm run build`

Реальный поиск и модель в этой версии не подключены. Источник таблицы — снимок запуска Apify от 2026-10-29.

# UI Checklist: Экран анализа ниши

**Purpose**: Проверка согласованного интерфейса и честной маркировки демо.  
**Created**: 2026-10-29  
**Feature**: [spec.md](./spec.md)

- [x] CHK001 Поле ограничено 150 символами; счётчик читается.
- [ ] CHK002 Под полем видны настройки и кнопка; пример формализации появляется после первого этапа загрузки.
- [ ] CHK003 Период 1/3/7 и лимит 1–50 доступны с клавиатуры в текущей версии (нужна браузерная проверка).
- [ ] CHK004 До запуска таблицы нет; после второго этапа она содержит реальные URL.
- [x] CHK005 По умолчанию лайки идут по убыванию.
- [x] CHK006 Комментарии и shares переключают порядок сразу.
- [ ] CHK007 Кнопка экспорта появляется вместе с таблицей; JSON соответствует текущим строкам и настройкам.
- [x] CHK008 Демо-источник и отсутствие живой модели обозначены явно.
- [ ] CHK009 На узком экране таблица остаётся доступной после последних изменений (нужна браузерная проверка).
- [x] CHK010 Дата сортирует от новых к старым (тест функции).
- [x] CHK011 Фильтр предлагает все слова из примера разбора с галочками; несколько отмеченных слов объединяются по «ИЛИ» (сверка разметки, тест функции).
- [ ] CHK012 Для слова без совпадений есть пустое состояние; JSON не выдаёт неподходящие записи (нужна браузерная проверка экспорта).
- [ ] CHK013 Формат расположен рядом с периодом; «Все / Только Reels / Только посты» применяются к таблице и JSON.
- [ ] CHK014 Лимит можно набрать вручную, после выхода из поля он находится в пределах 1–50.
- [ ] CHK015 После второго этапа таблица попадает в видимую область; под разбором есть ссылка к ней.
- [x] CHK016 Вне таблицы нет декоративных порядковых номеров, в таблице есть колонка «№» (сверка разметки).
- [x] CHK017 Кнопка подписана «Показать тренды» (сверка разметки).
- [ ] CHK018 Пустой выбор слов показывает все записи, сброс очищает галочки; JSON содержит массив выбранных слов.
- [ ] CHK019 Клик по тексту «макс. 50» и по области числа фокусирует ввод; первый набор заменяет прежнее число.

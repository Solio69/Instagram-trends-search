# Ревью: правила стиля и обязательное ревью

Проверен итоговый diff задачи по `spec.md`, конституции и `docs/code-style.md`.
Продуктовый код в этом проходе не менялся. Обязательное ревью находится в
действующем `speckit-implement` и в установленном пресете, а шаблон будущих
задач требует его до завершения.

## Замечания и исправления

- Упомянутого `Verge.md` в проекте нет. Пользователь подтвердил `AGENTS.md`;
  в нём добавлены только ссылки и команда gate.
- Локальное изменение версии `preset.yml` не обновило версию в регистрации
  Spec Kit. Номер оставлен `0.1.0`; `specify preset resolve tasks-template`
  выбирает установленный шаблон этого проекта.
- Первое описание области констант в style guide было уже, чем существующая
  структура кода. Уточнено, что значения доменной логики могут оставаться
  рядом с ней.
- В style guide добавлен отсутствовавший пункт о повторяющихся HTML-типах,
  ARIA/role-атрибутах и статических классах CSS-модулей.
- Первое решение включало ревью только внутрь `speckit-implement`, без
  отдельного скилла. По замечанию пользователя создан
  `.agents/skills/speckit-code-review/SKILL.md`; действующий implement skill,
  установленный источник и шаблон задач теперь требуют его вызова.
- Формулировка конституции уточнена: ревью проводится после завершения
  изменений кода, до итогового отчёта.
- Убраны лишние пробелы из новых документов. Итоговый diff этой задачи
  проходит `git diff HEAD --check`.

Блокирующих замечаний к итоговому рабочему содержимому задачи нет.
`git diff --cached --check` выявляет пробелы в уже staged документах задач
`003–005` и в устаревшем staged снимке документов `006`. Staging не менялся;
перед будущим коммитом нужно обновить индекс и повторить эту проверку.

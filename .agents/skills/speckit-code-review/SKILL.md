# Ревью кода после реализации

Применяй этот скилл после завершения изменений кода и до итогового отчёта
`speckit-implement`. При отдельном запросе на ревью сначала представь находки;
исправляй код только в рамках разрешённой задачи.

1. Прочитай `spec.md` текущей задачи, `.specify/memory/constitution.md` и
   `docs/code-style.md`. Определи согласованный объём и проверки из `plan.md`.
2. Проверь полный diff, включая staged, unstaged и untracked файлы. Отделяй
   изменения этой задачи от уже существующих изменений рабочего дерева.
3. Ищи прежде всего ошибки поведения, нарушение контракта и регрессии. Затем
   проверь поддерживаемость и соответствие style guide: существующие
   константы, границы абстракций, деструктуризацию, JSX, ошибки и фикстуры.
   Не придумывай требования и не требуй переписать неизменённый код без причины.
4. Запиши в `review.md` задачи находки с серьёзностью, файлом и строкой,
   объяснением и предлагаемым исправлением. Если находок нет, запиши это
   явно. Отмечай исправленные находки и оставшиеся ограничения.
5. В обязательном проходе `speckit-implement` исправь блокирующие находки в
   согласованном объёме, повтори затронутые проверки и запусти `npm run check`
   для изменений кода. Запиши реальные результаты в `verification.md`.
   Если блокирующая проблема или gate остаётся красным, сообщи об этом и не
   объявляй задачу завершённой.

Скилл не даёт разрешения на коммит, push, публикацию или расширение задачи.
